# Záměr autorského systému

## Potřebujeme

- mít přehled o úkolech, postavách, vztazích, světě, hotovém obsahu a otevřených otázkách;
- všechno prolinkovat v Obsidianu;
- používat Wayfinder tam, kde známe cíl, ale ne cestu;
- vizualizovat Wayfinder přes Wayfinder Maps v Obsidianu;
- verzovat celý vault v Gitu a používat GitHub Issues;
- využít jako inspiraci TTRPG vault patterny (entity, vztahy, scény, almanach), ale nepřenést D&D strukturu slepě;
- oddělit kánon, pracovní nápady, rozhodnutí a draft, aby se navzájem nepřepisovaly.

## Nechceme

- dvakrát udržovat stejnou informaci v issue a v poznámce;
- tisíc složek dřív, než víme, co potřebujeme;
- závislost na pluginu, bez kterého by text přestal být čitelný;
- tokeny nebo tajné údaje v Git historii;
- Wayfinder tickety typu „napiš kapitolu“ — Wayfinder má hledat rozhodnutí, ne nahrazovat psaní.
